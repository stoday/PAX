# ClockMate 工時填報助手

自動化工時表單填寫工具，支援批次處理和智慧填入。

## 安裝

### 從 GitLab 安裝
```bash
pip install git+https://gitlab.com/your-username/clockmate.git
```

### 從本地安裝
```bash
git clone https://gitlab.com/your-username/clockmate.git
cd clockmate
pip install -e .
```

## 使用方法

### 1. 取得登入憑證
```bash
~~clockmate~~-token
```

### 2. 執行工時填報
```bash
clockmate
```

## 功能特色

- 🚀 自動化工時表單填寫
- 🔐 安全的憑證管理
- 📅 智慧日期處理
- 🎨 美觀的命令列介面
- ⚙️ 可自訂工作時間設定

## 系統需求

- Python 3.10+
- Chrome 瀏覽器
- 網路連線

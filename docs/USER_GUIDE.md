## 選擇適合你的模式

Pax 提供兩種運行模式，請根據你的需求選擇：

### 🌐 雲端模式（推薦給大部分用戶）

**適合你，如果**：
- ✅ 希望快速安裝，立刻使用
- ✅ 有穩定的網路連線
- ✅ 不介意資料經過後端伺服器
- ✅ 希望自動更新，無需手動維護

**特點**：
- 📦 檔案小（20 MB）
- ⚡ 安裝快（< 1 分鐘）
- 🔄 自動更新
- ☁️ 需要網路連線

---

### 💻 本地模式（適合進階用戶）

**適合你，如果**：
- ✅ 需要離線使用
- ✅ 對資料隱私要求極高
- ✅ 願意花 3-5 分鐘安裝環境
- ✅ 能夠自行管理 API Keys

**特點**：
- 🔒 完全本地執行
- 📴 可離線使用
- 🔑 API Keys 自己管理
- 💾 需要安裝 Node.js + Python

---

### 📊 快速對比

| 項目 | 雲端模式 | 本地模式 |
|------|---------|---------|
| 下載大小 | 20 MB | 5 KB (腳本) |
| 安裝時間 | < 1 分鐘 | 3-5 分鐘 |
| 需要網路 | 使用時需要 | 只在安裝時 |
| 需要安裝環境 | ❌ 不需要 | ✅ 需要 |
| 離線使用 | ❌ 不行 | ✅ 可以 |
| 自動更新 | ✅ 是 | ❌ 否 |

**還不確定？** → 選擇雲端模式！隨時可以切換到本地模式。

## 本地模式安裝

### 步驟 1：下載安裝腳本

前往 [GitHub Releases](https://github.com/stoday/PAX/releases/latest) 下載：
- **Windows 用戶**：`setup_local.ps1` 或 `setup_local.bat`

### 步驟 2：執行安裝

#### 方法 A：使用 PowerShell 腳本（推薦）

1. 找到下載的 `setup_local.ps1`
2. **右鍵點擊** → 選擇「**以系統管理員身分執行**」
3. 如果出現安全提示，點擊「**執行**」

#### 方法 B：使用批次檔

1. 找到下載的 `setup_local.bat`
2. **右鍵點擊** → 選擇「**以系統管理員身分執行**」

### 步驟 3：等待安裝完成

安裝腳本會自動：
```
[1/5] 檢查 Chocolatey...
  ✓ Chocolatey 已安裝

[2/5] 檢查 Node.js...
  → 安裝 Node.js LTS...
  ✓ Node.js 安裝完成

[3/5] 檢查 Python...
  → 安裝 Python 3.10...
  ✓ Python 安裝完成

[4/5] 下載 Pax 程式...
  → 下載中...
  → 解壓縮中...
  ✓ Pax 下載完成

[5/5] 安裝依賴套件...
  → 安裝 Python 套件...
  → 安裝 npm 套件...
  ✓ 依賴安裝完成

╔════════════════════════════════════════╗
║   ✓ 安裝完成！                       ║
╚════════════════════════════════════════╝
```

**預計時間**：3-5 分鐘（視網路速度）

### 步驟 4：啟動 Pax

安裝完成後，你的桌面會出現「**Pax**」捷徑：

1. 雙擊桌面上的「**Pax**」圖示
2. 系統匣（右下角）會出現綠色圓點圖示 🟢
3. 右鍵點擊圖示 → 選擇「**打開 Pax**」

### 步驟 5：配置 API Keys（首次使用）

首次使用時，需要配置 Gemini API Key：

1. Pax 會自動開啟配置視窗
2. 或手動編輯：`C:\Program Files\Pax\.env`
3. 填入你的 `GEMINI_API_KEY`

**如何取得 Gemini API Key**：
1. 訪問：https://makersuite.google.com/app/apikey
2. 登入 Google 帳號
3. 點擊「Create API Key」
4. 複製 API Key 並貼到配置中

## 雲端模式安裝

### 步驟 1：下載執行檔

前往 [GitHub Releases](https://github.com/stoday/PAX/releases/latest) 下載：
- **Windows 用戶**：`PaxTrayApp-Cloud.exe`（20 MB）

### 步驟 2：執行程式

1. 找到下載的 `PaxTrayApp-Cloud.exe`
2. **雙擊執行**
3. 系統匣（右下角）立刻出現綠色圓點圖示 🟢

就這麼簡單！

### 步驟 3：開始使用

右鍵點擊系統匣圖示 → 選擇「**打開 Pax**」

## 常見問題

### Q1：如何切換模式？

**A**：目前需要重新安裝。未來版本會支援在系統匣選單中直接切換。

---

### Q2：雲端模式需要登入嗎？

**A**：不需要。Pax 會在需要時自動開啟瀏覽器，讓你登入工時系統或其他服務。

---

### Q3：本地模式可以完全離線使用嗎？

**A**：幾乎可以。除了呼叫 LLM API（Gemini）需要網路，其他功能都可以離線使用。

---

### Q4：如何更新 Pax？

**雲端模式**：
- 自動更新，無需手動操作

**本地模式**：
1. 下載最新的 `setup_local.ps1`
2. 重新執行安裝腳本
3. 安裝腳本會自動備份你的配置

---

### Q5：如何卸載 Pax？

**雲端模式**：
1. 右鍵系統匣圖示 → 選擇「結束常駐」
2. 刪除 `PaxTrayApp-Cloud.exe`

**本地模式**：
```powershell
# 1. 停止 Pax
taskkill /F /IM "PaxTrayApp.exe" /T

# 2. 刪除程式檔案
Remove-Item -Recurse -Force "C:\Program Files\Pax"

# 3. 刪除桌面捷徑
Remove-Item "$env:USERPROFILE\Desktop\Pax.lnk"

# 4. （可選）卸載 Node.js 和 Python
choco uninstall nodejs-lts python310 -y
```

---

### Q6：系統匣找不到圖示？

**A**：
1. 檢查工作管理員是否有 `PaxTrayApp.exe` 在運行
2. 點擊系統匣的「^」（展開隱藏圖示）
3. 如果還是找不到，重新啟動 Pax

---

### Q7：出現「找不到 API Key」錯誤？

**雲端模式**：
- 不需要配置 API Key，這是後端的錯誤，請聯繫管理員

**本地模式**：
1. 確認 `C:\Program Files\Pax\.env` 檔案存在
2. 確認檔案中有 `GEMINI_API_KEY=...`
3. 確認 API Key 正確（無多餘空格）
4. 重新啟動 Pax

---

### Q8：如何查看錯誤日誌？

**雲端模式**：
- 日誌位置：`%APPDATA%\Pax\logs\pax.log`

**本地模式**：
- 日誌位置：`C:\Program Files\Pax\logs\pax.log`

查看方式：
```powershell
# 查看最後 50 行
Get-Content "C:\Program Files\Pax\logs\pax.log" -Tail 50
```

---

### Q9：可以同時運行兩種模式嗎？

**A**：不建議。兩種模式會競爭系統匣圖示和埠號，可能導致衝突。

---

### Q10：忘記 Gemini API Key 了怎麼辦？

**A**：
1. 訪問：https://makersuite.google.com/app/apikey
2. 查看現有的 API Keys
3. 或建立新的 API Key
4. 更新到 `.env` 檔案中

## 快速入門

Pax 現在提供**免安裝的可攜式版本 (Portable Distribution)**，解壓縮即可啟動。

### 步驟 1：取得程式
1. 從發佈頁面下載 `Pax-Portable.zip`。
2. 將其解壓縮到您想要的目錄（建議路徑：`C:\Tools\Pax`）。

### 步驟 2：啟動 Pax
1. 進入解壓後的目錄，點擊執行 **`Pax.bat`**。
2. 系統匣（右下角）會出現綠色圓點圖示 🟢，代表 Pax 已在背景執行。

### 步驟 3：配置 API Key (首次啟動)
1. 找到目錄下的 `.env` 檔案（或透過系統匣選單開啟配置）。
2. 在 `GEMINI_API_KEY` 欄位填入您的 API 金鑰。
3. 儲存檔案並重新啟動 Pax。

## 模式說明

Pax 支援兩種運行模式，並可以在系統匣介面隨時切換：

### 🌐 雲端模式 (Cloud Mode)
- **特點**：邏輯運算在遠端伺服器進行，回應速度快。
- **適用**：大部分日常行政、工時填寫需求。

### 💻 本地模式 (Local Mode)
- **特點**：所有邏輯都在您的電腦本地執行，隱私保護更完善。
- **適用**：處理機敏資料、或需要離線運行時。

## 使用方式

### 系統匣選單 (Tray Menu)
右鍵點擊系統匣的綠點圖示，可執行以下操作：

- **打開 Pax Console**：開啟 AI 對話視窗。
- **模式切換**：快速切換 [本地] 或 [雲端] 模式。
- **取得 Token**：當認證失效時（如工時填寫錯誤），可用此功能自動重新登入並抓取 Token。
- **結束常駐**：完全關閉 Pax。

### AI 對話範例
啟動 Console 後，您可以直接輸入自然語言要求：

- 「幫我填今天的工時，9 點到 6 點，原因忘刷」
- 「幫我查詢今天去高雄出差的交通費」
- 「幫我分析這份文件的摘要」

## 常見問題

### Q1: 點擊 Pax.bat 閃現一下就沒了？
**A**: 請開啟 CMD 視窗，切換到該目錄並執行 `Pax.bat --debug`，這會顯示詳細報錯。通常是因為 `.env` 配置有誤。

### Q2: 出現 "No module named 'runtime'" 錯誤？
**A**: 這是舊版路徑識別問題。新版已修復，請確保您解壓縮了整個包含 `runtime` 資料夾的套件內容。

### Q3: 本地模式需要另外安裝 Python 或 Node.js 嗎？
**A**: **不需要**。可攜式版本已內建了專屬的 Python 與 Node.js 執行環境，不會影響您目前的電腦系統設定。

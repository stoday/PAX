=== Pax 便利工作助手 ===

請選擇以下其中一種模式安裝：

╔════════════════════════════════════════════════════════════╗
║  【雲端模式】（推薦給大部分用戶）                          ║
╚════════════════════════════════════════════════════════════╝

下載：PaxTrayApp-Cloud.exe
大小：20 MB
安裝：雙擊執行，立刻可用
優點：安裝快速、自動更新、無需配置
缺點：需要網路連線

適合：
✓ 希望快速安裝的用戶
✓ 有穩定網路連線
✓ 不想安裝額外軟體


╔════════════════════════════════════════════════════════════╗
║  【本地模式】（適合需要離線使用的用戶）                    ║
╚════════════════════════════════════════════════════════════╝

下載：setup_local.ps1 或 setup_local.bat
大小：5 KB（會自動下載依賴）
安裝：右鍵 → 以系統管理員身分執行
優點：可離線使用、隱私保護、完全本地執行
缺點：需要安裝 Node.js + Python（約 3-5 分鐘）

適合：
✓ 需要離線使用
✓ 對隱私要求極高
✓ 願意花時間安裝環境


════════════════════════════════════════════════════════════

【安裝步驟】

雲端模式：
1. 下載 PaxTrayApp-Cloud.exe
2. 雙擊執行
3. 系統匣出現綠色圓點圖示
4. 右鍵點擊圖示 → 選擇「打開 Pax」

本地模式：
1. 下載 setup_local.ps1（或 setup_local.bat）
2. 右鍵 → 以系統管理員身分執行
3. 等待 3-5 分鐘自動安裝
4. 桌面出現「Pax」捷徑
5. 雙擊捷徑 → 系統匣出現綠色圓點圖示
6. 右鍵點擊圖示 → 選擇「打開 Pax」
